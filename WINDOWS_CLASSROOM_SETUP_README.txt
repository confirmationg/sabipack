SABIPACK CLASSROOM SETUP — WINDOWS 64-BIT

1. Extract this ZIP to a folder on your Windows laptop.
2. Connect to the internet for this one-time setup.
3. Double-click Install_SabiPack_Classroom.bat and allow it to finish.
   It downloads the official portable Node.js runtime and installs SabiPack.
4. Open https://sabipack.vercel.app/ and choose Teacher.
5. Turn on Windows Mobile Hotspot or connect to the classroom router.
6. Click Start My Local Classroom. Share the student address shown on the dashboard.
7. If Windows Firewall asks, allow Node.js on Private networks so students can connect.

AFTER SETUP
- The local classroom server and locally stored teacher resources work without internet.
- Students must join the same Wi-Fi/hotspot as the teacher laptop.
- Groq-powered AI lesson generation still needs internet in this version.
- Windows Hotspot must be enabled manually before starting the classroom.

The installer downloads Node.js 26.13.0 from the official nodejs.org distribution site.
This package supports 64-bit Windows. It is not an .msi installer; it is a ZIP setup package with a one-click Windows setup script.
