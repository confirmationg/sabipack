Host a class

One device serves the app and its packs to a whole class over local Wi-Fi. No internet needed in the room.
From a laptop
1. Install Node.js once. Copy the SabiPack project folder to the laptop.
2. Turn on the laptop’s hotspot, or join the classroom router.
3. Run node classroom/server.mjs and write the address it prints on the board.
From an Android phone (Termux)
1. Install Termux from F-Droid (the Play Store version is out of date).
2. Connect to the internet once, then paste this in Termux:
3. Turn on the phone’s hotspot. Students join it and open the address Termux shows. If none is shown, use the hotspot address in your phone settings (often 192.168.x.1) followed by :8080.
4. Keep Termux open while the class is using it.
Honest notes: a phone’s browser cannot run a server by itself, which is why Termux is needed. Tested on a computer. Not yet tested on a real phone. Phone hotspots limit how many devices can join.
No hotspot? Use Share to send a pack by Bluetooth or Nearby Share. That works on any phone.
