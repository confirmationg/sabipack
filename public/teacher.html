TEACHER WORKSPACE

Bring your classroom online — even when the internet is offline.

Use your Windows laptop as a local classroom hub. Publish lesson files over your own Wi-Fi or Mobile Hotspot so students can access them without mobile data.

1. Download classroom setup

Download the dedicated Windows setup package. It includes SabiPack's classroom files and installs a portable Node.js runtime automatically.

Download Classroom Setup ↓
  1. Extract the downloaded ZIP.
  2. Double-click Install_SabiPack_Classroom.bat.
  3. Keep internet on during this one-time setup so the installer can download the official Node.js runtime.

No separate Node.js installation is required. Setup is for 64-bit Windows.

2. Start a classroom

After setup, return here whenever you want to host a class. The installed classroom server runs locally and does not need internet.

  1. Turn on Windows Mobile Hotspot or connect to the classroom Wi-Fi router.
  2. Click the button below and allow the browser to open SabiPack Classroom.
  3. If Windows Firewall asks, allow Node.js on Private networks so students on the same hotspot/router can connect.
  4. The local Teacher Dashboard opens with the student address and resource upload form.
Start My Local Classroom ↗

What students do

  1. Join the same Wi-Fi or hotspot.
  2. Open the student address shown on the Teacher Dashboard.
  3. Open or download the teacher’s PDF, PPT, PPTX or text resource.
  4. Import a SabiPack file or use Pack Studio to turn supported notes into a personal pack. Saved packs can be studied offline and shared with classmates.
Important: connect to the internet for the one-time setup download. After installation, the local classroom and saved packs work without internet over the same Wi-Fi or hotspot. AI lesson generation still uses the online Groq service and therefore needs internet. Offline AI is planned, not included in this build. The helper cannot switch on Windows Hotspot automatically; turn it on in Windows settings before starting the classroom.
